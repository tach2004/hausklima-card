# Dashboard-Beispiele

Installiere HausKlima Card und lade die JavaScript-Ressource, bevor du die Beispiele einfügst. Ordne danach die Sensoren im grafischen Karteneditor zu.

| Datei | Einfügeort |
| --- | --- |
| [panel.yaml](panel.yaml) | YAML-Editor einer Panel-Ansicht. Diese Ansicht gibt der Karte die verfügbare Breite. |
| [sections.yaml](sections.yaml) | YAML-Editor einer Sections-Ansicht. Die Breite folgt der Sektion. |
| [basic.yaml](../basic.yaml) | YAML-Editor einer einzelnen Karte. |

Für die vollständige Dashboard-YAML fügst du eine der beiden Ansichtsdateien als eingerücktes Listenelement unter `views:` ein.
