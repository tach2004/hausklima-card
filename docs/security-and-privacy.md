# Sicherheit und Datenschutz

Beispiele und Aufnahmen verwenden synthetische Messwerte. Zugangsdaten, private Kontaktinformationen und produktive Home-Assistant-Konfigurationen gehören nicht in das öffentliche Repository. Prüfe Bilder vor dem Hochladen auf sichtbare Daten und Metadaten.

Verwende für Autor und Committer eine GitHub-Noreply-Adresse. GitHub zeigt die Adresse für dein Konto in den [E-Mail-Einstellungen](https://github.com/settings/emails) an.

Die automatischen Prüfungen kontrollieren Abhängigkeiten, typische vertrauliche Muster in Textdateien und Commit-Metadaten im PR. Prüfe Änderungen vor dem Push auch selbst, insbesondere Binärdateien und Screenshots. Melde vertrauliche Inhalte auf einem privaten Weg.
